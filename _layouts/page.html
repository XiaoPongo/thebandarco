Hollow Text Parallax Effect

How It Works

The hollow text effect is created using transparent text with a white stroke. Multiple layers create a parallax effect when scrolling.

CSS properties used:

  • color: transparent
  • -webkit-text-stroke
  • text-stroke
  • Text shadows for glow effect

Parallax Scrolling

Each text layer moves at a different speed based on its depth value:

gsap.to(layer, {
  y: (1 - depth) * 50,
  scrollTrigger: {
    scrub: true
  }
});

Higher depth values move slower, creating a parallax effect.

Customization

You can customize this effect:

  • Change stroke width and color
  • Adjust opacity for each layer
  • Modify the parallax intensity
  • Add more layers for depth
  • Change the glow effect
